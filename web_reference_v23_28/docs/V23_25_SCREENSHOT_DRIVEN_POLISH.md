# V23.25 Screenshot-driven polish

Based directly on mobile landscape gameplay captures.

Fixes:
- HUD safe zones: status, quest, target/combo, minimap, toasts and action cluster no longer fight for the same screen space.
- Toast stack capped to three visible entries.
- Action labels reduced and separated.
- Minimap reduced and less visually noisy.
- Enemy HP/name information is contextual instead of permanently shown for every nearby mob.
- Added subtle low-cost ground composition in sparse areas.
- Added player readability halo so the hero remains readable in dense foliage.
- Preserved dense biome dressing, but reduced informational clutter over it.
- Existing staff, party, raid/event and LAN backend systems remain intact.
